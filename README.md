## Description:
This website is inspired by the *JoJo's Bizarre Adventure* series specifically Tonio's restaurant and the dishes featured in the show. The goal is to create a web-based version of the restaurant, showcasing its menu, dishes, and various elements related to Tonio's cuisine. The primary entities are the restaurant's dishes, while the secondary entities are the ingredients for each dish, along with the healing effects they provide.

## Functionality:
### Entities:
- Main entity: Dishes
- Main entity Attributes: Healing properties, Dish description, Type of meal, Chef, Food critic review, Price
- Secondary entity: Ingriedents
- Secondary entity Attributes: Lactose intolerancy, Celiac, Organic
  
### Images:
**Main entity:** Each dish has an associated picture representing the meal.

### Filter:
- Type of meal (Antipasti, pasta, pizza, dessert...)
- Vegan dishes
- Organic dishes
- Celiac dishes
